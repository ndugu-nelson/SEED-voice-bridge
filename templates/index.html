Pick a finding and language, then press Run agent.
  • The API key lives on the server, not in the browser. This is a real Python (Flask) app — every Sunbird AI call (simplify, translate, voice) and the NAROIR search happen in app.py, server-side, using an environment variable for the key. The frontend calls only this app's own /api/... routes and never sees the key.
  • Same origin, no CORS to fight. Because the Flask app serves both the page and the API, there's no cross-origin request at all from the browser's point of view — it simplifies the whole plumbing compared to calling third-party APIs directly from client-side JS.
  • The repository query is real. The search box calls NAROIR's public OpenSearch feed at irbackend.naro.go.ug, proxied through this app's backend. If that upstream call fails, the results list says so explicitly and falls back to a small cached snapshot of real NARO findings rather than failing silently.
  • Radio-first, matching the evidence. 44% of farmers cite radio as an information source versus under 1% for internet — so the pipeline's end product is a broadcast script, not a push notification.
  • Partners instead of building from scratch. Sunbird AI, a Kampala-based lab, runs an open-source translation system (the SALT dataset — 25,000 parallel sentences, including agriculture) across Luganda, Runyankole, Ateso, Acholi and Lugbara, a working text-to-speech model per language, and Sunflower — a Ugandan-built multilingual LLM with an OpenAI-compatible chat API, used here for the simplify step.
  • Honest either way. If the server is missing its Sunbird key, or a downstream call fails, that specific step says so plainly and shows a clearly labeled fallback — never a silent failure, never pretending a canned result is live.
Prototype for interview demonstration only. Cached-snapshot findings and offline fallback text are clearly labeled and drawn from NARO's own published materials. Sunbird AI and NAROIR facts are drawn from their public materials as of 2025/2026.
